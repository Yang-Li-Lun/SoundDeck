# WF-1000XM5 實機確認清單

SoundDeck **v0.10.0** 的下列實機項目尚未完成驗收。測試前取得裝置持有人同意，保留配對、音訊模式、韌體及原設定。新的 Debug 金鑰不能覆蓋不同簽章 APK，請使用獨立測試裝置，不為測試刪除日用資料。

## 連線與狀態

- 記錄手機、Android、Launcher、耳機韌體、音訊模式及 Sound Connect 使用情況；分享前遮蔽位址與裝置識別資料。
- 使用既有配對記錄與控制通道，核對 MDR 型號、能力與初始回報。GATT 成功不等於 LC3 播放中，不能確認的資訊保留未知。
- 手動中斷、斷線、前景重連及藍牙關閉／恢復後，確認舊 Session 釋放、即時值清除並重讀，沒有第二個 Session 或無限重試。
- Classic／RFCOMM 僅在持有人原本使用或另行同意的情境測試，不為驗收切換既有 LE Audio 設定。

## 控制與同步

- ANC／Ambient／Off、Ambient 1／7／10／19／20、App 聚焦人聲、EQ 預設與六段自訂、DSEE、Speak-to-Chat 開關及三份電量分別回歸，完成後恢復原值。
- Speak-to-Chat 靈敏度只在 Type 2 能力與有效回報後測自動／高／低；比對耳機與官方 App，確認保留自動結束時間與開關。ACK 或畫面改變不能單獨當作成功。
- App、Widget、Tile 共用控制狀態；Widget 只有三模式、十個強度刻度與 EQ，沒有聚焦人聲開關。通知只顯示狀態。
- 寫入拒絕、不符回讀、未知格式、逾時與斷線不得顯示成功。外部切換模式後，過時的 Widget 操作不得覆寫成錯誤模式。
- 電量依左耳／充電盒／右耳歸屬，0 是有效值，未知不得轉成 0；充電盒不保證持續回報。斷線清除，不將 Launcher 快取當即時資訊。

## 顯示與音訊

- Widget 4×3、250×180dp 起、放大尺寸、明暗主題、大字體、橫向及不同 OEM Launcher：文字、三模式、十段與 EQ 不遮擋。低於最小高度時記錄觸控空間限制。
- App 深淺色／動態色、短視窗、權限提示、成功藥丸淡出與錯誤訊息在原手機確認。
- 保持既有 LC3 音樂播放，確認控制期間音訊是否中斷；Sound Connect 共存、多點與背景可靠性分開記錄，不以其他通道通過代替。

每項記錄預期、實際與通過／失敗／未知；無法安全執行的項目保留未執行。
